# plugreports.com

Harm-reduction library: 92 street-drug profiles, busts, news, guides,
day-by-day quit timelines, hotlines, sentencing tables, verified directories.

## Stack
- Static site generated by `src/build.py` from `src/data_*.py` (edit data, rebuild)
- Cloudflare Pages (`public/`) + Pages Functions (`functions/api/`) + KV (`CONTENT`)
- Admin panel at `/admin` (PIN-protected; content API backed by KV)
- i18n UI strings for top-10 languages in `public/assets/js/app.js`
- PWA: `manifest.webmanifest` + `sw.js`

## Build & deploy
    python3 src/build.py

## Drug images
Drop webp/jpg at `public/assets/img/drugs/<slug>.webp` (slug = file name in
`src/data_drugs.py`). Missing images fall back to a placeholder automatically.
